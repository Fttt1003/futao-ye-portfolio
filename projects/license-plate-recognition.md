# License Plate Recognition

**Python · OpenCV · Image processing · Template matching**

## Overview

A coursework project exploring recognition of mainland Chinese and Hong Kong license plates. The project combines image preprocessing, plate rectification, character segmentation and template-based recognition.

## Approach

- Locate candidate plate regions using HSV colour masking and morphological processing.
- Apply perspective rectification and projection-based character segmentation.
- Combine image difference, edge similarity and contour matching for template recognition.
- Visualise intermediate outputs to inspect and debug the processing pipeline.
